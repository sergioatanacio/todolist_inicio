# Terraform

Esta carpeta queda reservada para el aprovisionamiento en Google Cloud.

Direccion recomendada:

- Cloud Run para el backend.
- Firestore en modo nativo como base de datos.
- Firebase Authentication para login con Google.
- IAM y service accounts gestionadas por Terraform.

Estructura:

- `environments/dev`: configuracion de desarrollo.
- `modules/`: modulos reutilizables.
